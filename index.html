Onde quer guardar os dados?

O Orbe usa uma base de dados SQLite. Escolhe onde guardar os registos deste negócio.

No telemóvel, os dados ficam no armazenamento privado do navegador. Num computador compatível, também podes guardar o ficheiro orbe.sqlite numa pasta escolhida.
